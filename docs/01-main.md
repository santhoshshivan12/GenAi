# `main.py`

This file is the entry point.

## What it does

- starts the FastAPI app with Uvicorn
- points Uvicorn to `rag.api:app`
- runs on `127.0.0.1:8000`

## Why it exists

It gives you a single command to start the project:

```bash
python main.py
```

## In simple terms

Think of `main.py` as the launch button.
